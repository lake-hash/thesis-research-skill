# Final Reader And Source Review Stage

Review the finished deterministic presentation, not the writer's draft or a
sample. Bind the result to the exact presentation hash. Changed prose, source,
date, ticker, direction, media, grouping or visibility invalidates prior review.

For every visible current card and dated event verify:

- attribution and exact source fidelity;
- standalone investment what, why and landing;
- source-date chronology and no future evidence;
- exact expression-local ticker set and one supported direction per ticker;
- complete media disposition and surviving included images;
- conclusion-first professional language, complete mechanism and advancing body;
- no process, portfolio-operation, technical-only or repeated language;
- 500-character limit and named original link/date agreement.

Run corpus checks on the actual rendered order:

- current-card opening distribution;
- each company's ordered Timeline;
- `temporal-feed-opening-diversity/1.0` across all dated Feed items, including
  neighboring rows from different records.

Run candidate conservation against the original triage ledger. Any complete
candidate absent from public output or pending needs an exact evidence-bound hard
failure under `triage-candidate-accounting/1.0`.

Return `final-public/1.3` with one reviewed row per visible expression and exact
total/completed counts. `repetition_free`, ticker/media completeness and other
pass fields are derived from deterministic checks; never assert them to waive an
error. Approval is content approval only, not publication authorization.
